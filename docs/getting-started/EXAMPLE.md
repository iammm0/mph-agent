# 快速案例：牛顿环等厚干涉实验

本文档只保留当前项目唯一需要智能体自行仿真建模并测试成功的快速案例：牛顿环等厚干涉实验。桌面端新会话空状态中的“牛顿环仿真建模”按钮会直接切换到执行模式并触发该案例，不再展示额外使用流程或其他快速示例。

## 案例目标

快速案例用于验证 mph-agent 是否能把一个完整光学实验需求转成可执行的 COMSOL 建模流程，并在桌面端展示智能体的推理、操作、观察和结果导出事件。

该案例要求最终形成一个可复现实验模型：

- 实验结构包含上方平凸透镜、下方光学平板或平面镜，以及二者之间中心厚度接近 0 的空气薄膜。
- 采用 2D 轴对称建模作为优先方案；若全波光学计算代价过高，可使用薄膜干涉或 Fresnel 反射/透射等效模型。
- 需要保留平面反射界面、凸面界面、空气膜厚度随半径变化 `t(r)`、入射光、反射光和透射光路径。
- 反射观察通道中应能得到中心暗斑和同心明暗环。
- 至少扫描 486.1 nm、546.1 nm、589.3 nm、632.8 nm 四种单色光，并导出对应图像与汇总数据。

## 建模要素

牛顿环属于等厚干涉。平凸透镜放在平板上时，两者之间形成空气薄膜；薄膜厚度随半径增加而增加，反射光在空气膜上下表面之间发生干涉。反射观察时，由于空气膜下表面反射存在半波损失，中心接触处应出现暗斑。

智能体建模时必须覆盖这些要素：

- 几何：平凸透镜、平面镜或平玻璃板、空气薄膜、有效口径、观察截面。
- 参数：波长、透镜曲率半径、玻璃折射率、空气折射率、口径、入射强度、反射率/透射率、可选吸收损耗。
- 物理：正入射或近轴入射、玻璃-空气界面反射和透射、空气-玻璃界面反射和透射、半波损失、相位差、光强叠加。
- 损耗：Fresnel 反射率和透射率应参与能量分配；如采用材料吸收，可在模型说明和导出数据中标明。
- 后处理：输出不同单色光下的反射光强分布、同心环图像、典型暗环或亮环半径。
- 校验：使用反射暗环半径关系 `r_m = sqrt(m * R * lambda)` 或等价公式，对前几级环半径进行解析对比。

请加入解析校验：使用反射牛顿环暗环半径关系 r_m = sqrt(m * R * lambda) 或等价公式，对前几级环半径做对比，并把校验结果写入导出数据或模型说明中。

## 成功判据

该快速案例不是普通展示文案，而是桌面端唯一快速建模测试入口。一次成功运行至少应满足：

1. 桌面端点击“牛顿环仿真建模”后直接进入执行模式并开始建模。
2. 建模过程事件默认展开，能看到规划、能力扫描、推理、执行、观察、结果同步等阶段。
3. 模型中包含平凸透镜、平板/平面镜和空气膜的物理含义。
4. 单色光参数扫描覆盖 486.1 nm、546.1 nm、589.3 nm、632.8 nm。
5. 结果能展示中心暗斑和同心明暗环，且不同波长下环间距有可见差异。
6. 输出目录中包含四张牛顿环图像和 `output/newton_rings_summary.csv`。
7. 汇总数据或模型说明中包含解析环半径校验结果。

## 启动策略

源码调试时优先使用：

```bash
uv run python main.py
```

`main.py` 会强制使用 Tauri + Vite 开发模式，以确保每次启动都加载当前仓库里的最新桌面端源码，而不是旧的 release 构建产物。若需要显式使用开发入口，也可以运行：

```bash
uv run python cli.py dev
```

`uv run python cli.py` 仍保留“有 release 可执行文件时优先启动 release”的行为，适合验证打包产物；日常开发和检查中文桌面文案时应使用 `main.py` 或 `cli.py dev`。
